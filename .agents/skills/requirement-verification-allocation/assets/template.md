## Requirement Verification Matrix

PRDに定義された検証対象と、その検証を担当するModuleの対応関係および検証状況を示す。

### **Verification Status**
各表で管理するStatusを下記にて定義する。

| Status | Definition |
|---|---|
| `TODO` | Verificationが未完了の状態。Requirement Verification Matrix作成時の初期値とする。 |
| `VERIFIED` | 担当ModuleによるVerificationが完了し、その結果が確認された状態。 |
