# Usage Examples

## Initial Idea Examples

### Example 1: アイデアを広げたい場合
> 開発者向けのタスク管理ツールのアイデアがあります。基本的なCRUD機能に加えて、開発者ならではの価値を提供したいです。どんな機能があれば、既存のツール（Todoist、Trello、Asanaなど）と差別化できるでしょうか？ブレインストーミングに付き合ってください。

### Example 2: 具体的なアイデアがある場合
> システムエンジニアが、個人開発を通じてスキルの習得やpocを試したい時に、「学びたい技術」を示した時、生成AI  apiを活用して、それを用いた実装課題を提案するようなアプリを作りたい。他にも「難易度」「所要時間」などを受け取って、課題を設定する際の考慮要素にしたい。
